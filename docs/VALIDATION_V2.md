- 固定上游 + 累积补丁的适用 Go 回归与 `go build -trimpath` 通过，仍仅排除 Windows 不适用的 Unix owner-only mode 断言。

- 旧启动器 4 项、readiness 5 项、完整入口 6 项回归通过。新入口检查默认提示词/原生工具保留、进程级路由、原设置不改、发现目录与 OAuth 不复制、错误进程拒绝、陈旧记录清除，以及外部账号/日志环境变量不污染网关。

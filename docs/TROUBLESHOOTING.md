# 故障排查

| 现象 | 检查与处理 |
|---|---|
| 找不到 Go/Python/Git/Claude | 安装后重新打开终端；用 INSTALL_WINDOWS 中的版本命令检查。非默认安装用 tools.local.ps1 指定 exe，避免 Windows Store 别名和 WSL bash |
| PowerShell 不允许运行下载脚本 | 检查 ZIP 属性“解除锁定”并重新解压；使用项目提供的进程级 Bypass。组织限制需按组织政策处理 |
| GitHub 下载或 Go 依赖失败 | 看最后一条错误；确认当前网络可访问对应服务后重跑 Setup。脚本不永久修改代理或切换镜像 |
| `_source` 版本或补丁校验失败 | 保留本地改动，使用新的解压目录；不要忽略错误在未知源码上编译 |
| 8081 被占用 | 用自己的旧网关停止入口关闭，或只修改本项目 runtime/config.yaml 的端口。不要结束不明进程 |
| token_v2 找不到 | 先确认登录、页面域名、Application → Storage → Cookies；Windows 用 F12/Ctrl+Shift+I，顶部面板折叠时展开 » |
| 账号已添加但 usable_accounts 为 0 | 在 Notion 核对所选工作区权益、额度和会话；同名工作区也可能不同。账号导入与可推理不是同一检查 |
| Overloaded/529 或“暂时不可用” | 先看 usable_accounts 和工作区额度，再看本机日志。实测曾是工作区不可用，不足以只凭该提示认定上游拥堵 |
| 模型不可用或上游确认不一致 | 检查当前工作区是否可用 Opus 5.5；保留失败记录，勿改回 Auto。模型字段缺失也会有意报错 |
| 返回 400、未知工具或插件出错 | 关闭普通 CLI 入口，使用本工具包的 Claude-Code.cmd；当前通道只验收精简工具，未加载完整 MCP/插件 |
| 模型返回命令但目录/文件没出现 | 核对是否实际调用工具及成功结果，按 ACCEPTANCE 重新做小任务。模型文本不是执行证明 |
| 请求意外指向 Sonnet | 检查是否从旧会话或其他启动器进入；关闭后使用本项目入口。默认 acceptEdits 避免验收版本自动权限分类器的 Sonnet 请求 |
| Bash 路径与 Windows 路径写法不同 | Git Bash 的 /d/... 可对应 D:\...；先 pwd 确认位置，在工作目录用相对路径处理中文文件 |
| 清理提示仍有 Claude 会话 | 先退出本项目会话；清理按 PID/路径/启动时间判断，不会结束其他项目的 Claude |
| 清理拒绝重定向路径 | 项目或子目录含符号链接/junction；先确认实际目标，别通过删除外部目标解决。普通完整解压目录支持清理 |

分享错误时只提供版本、出错阶段、脱敏后的错误句和可复现步骤。不要附完整 config、accounts、日志目录或 Cookie 面板截图。请求超时后上游任务可能继续，先查看结果再决定是否重试。
